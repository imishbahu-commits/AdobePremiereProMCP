# Reference pipeline — style recreation episode "v1"

Working reference implementation of the skill's Phase 2. These are the exact files
that rendered the shipped 78s episode, copied unmodified from the workspace
(`outputs/demo/`) so the technique is inspectable even though the heavy artifacts
(videos, AI-generated plates) stay out of git per the repo's `outputs/*` ignore rule.

| File | Role |
|---|---|
| `gen_render_v1.py` | PIL plate factory (numerals, ladder, chips, bubbles, sunbursts, title cards, hand-drawn ★) **and** the filtergraph builder — run it first, it emits `filtergraph_v1.txt` |
| `run_v1.sh` | Full stage order: probe VO → plates+graph → 38-input render → audio mix → mux → poster |
| `filtergraph_v1.txt` | The generated 55-line `filter_complex` script (regenerated by the .py; committed as study material — note the `split=2/3` label-clone pattern and `between(t,…)` window gating) |
| `aud_v1.txt` | The audio `filter_complex_script`: aformat normalization → adelay VO drops → synth bed → sidechain duck → loudnorm |

## Layout

This folder is **fully self-contained for rebuilding** — the creative inputs that
cannot be regenerated byte-identical are versioned here:

- `assets/` — the eight AI-generated chroma plates (room, hero_down, hero_up,
  hamster, bar, box, space, jag), flat-2D on pure `#00FF00` except full-frame
  backgrounds. `v1_box.png` is post-despill (see SKILL.md chroma recipe).
- `vo/` — the four narration drops (`vo_01` + `vo_b/c/d`), placed at
  1.0 / 30.8 / 43.8 / 58.2 s by `aud_v1.txt`.
- `gen_render_v1.py` regenerates the 31 PIL plates (numerals, ladder, chips,
  sunbursts, titles, ★) + `filtergraph_v1.txt`.

## To actually run it

1. Provide an ffmpeg static build (`ffmpeg_x64` in the run dir; a 2018-era build was
   used — see SKILL.md for its quirks, or adapt the scripts for a modern ffmpeg)
   and a Pillow install (`PYTHONPATH=<pillow>`).
2. Copy this whole `pipeline/` folder to a work dir; keep the `assets/`, `vo/`,
   `plates/` layout the scripts expect (`gen_render_v1.py` creates `plates/`).
3. `PYTHONPATH=<pillow> python3 gen_render_v1.py && bash run_v1.sh`
4. QA: extract frames at every beat timestamp and *view them* before shipping.

The finished episode (78 s, 1080p30, −14.7 LUFS) is attached to the git tag
release `recreation-v1` as `v1_recreation_cut2.mp4` — the rendered deliverable
is durable without bloating the git history.
